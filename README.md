# OrbitFood

Full-stack, multi-tenant food ordering application — separate admin, tenant (restaurant), and customer portals, with an AI assistant ("Alica") answering role-scoped questions in each one.

- [`orbitfood-backend/`](orbitfood-backend/) — Node.js/Express + Sequelize API server
- [`orbitfood-frontend/`](orbitfood-frontend/) — Vite + React/TypeScript client (admin, tenant, and customer portals in one app)
