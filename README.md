# Food

Full-stack, multi-tenant food ordering application — separate admin, tenant (restaurant), and customer portals, with an AI assistant ("Alica") answering role-scoped questions in each one.

- [`chpl-food-backend/`](chpl-food-backend/) — Node.js/Express + Sequelize API server
- [`chpl-food-frontend/`](chpl-food-frontend/) — Vite + React/TypeScript client (admin, tenant, and customer portals in one app)
